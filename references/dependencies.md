# 依赖调用契约

只加载本次分支需要的 Skill。优先使用运行时 Skill 调用入口；没有专门入口时读取实际 `SKILL.md` 并按其流程执行。常见安装根是 `~/.codex/skills`，也可能在运行时列出的其它位置；不要用作者机器的绝对路径。

## 封面：punk-cover

预检文件：`SKILL.md`、`references/cover-prompt-blueprint.md`、`references/style-catalog.md`；微信再读 `references/wechat-dual-crop.md`。共享风格从 `~/.codex/styles/{style-id}/META.md` 与 `STYLE.md` 读取，安装目录不同则按依赖实际路径解析。只有 `outputs` 包含 `cover` 或 `poster` 的风格可用；不要将风格实现复制进本仓库。

传入字段：平台、短标题、源文摘要、视觉隐喻、已选风格、画幅／尺寸、输出模式、明确的提示词与图片输出路径。用户 `auto` 时可选风格并报告理由；其余遵守依赖确认门。

| 分支 | 必传约束 | 必收产物 |
| --- | --- | --- |
| 微信 | `WeChat public account`；`wechat-dual-crop-master`；2010×600；左 1410×600，右 600×600，各有完整标题和主视觉 | 完整提示词、上传母版、精确横版、精确方版 |
| X | `X`；读取当前文档的 X 画幅，当前为 5:2；按该比例独立构图；记录实际像素 | 独立完整提示词、独立封面 |

微信精确裁切坐标：横版 `(0, 0, 1410, 600)`，方版 `(1410, 0, 600, 600)`，格式为 x、y、宽、高。不能把一张普通横版拉伸成母版；方版只有背景、标题缺字或主视觉不完整均不合格。X 如生成像素略有偏差，按依赖允许的等比缩放／裁切验收，不能牺牲标题与主体。

委托现有 Skill 处理生成和允许的尺寸导出；编排器只接收明确返回的本次文件并验收。不从图片预览推断本地文件已保存。

## 排版：gzh-design（可选）

将源文、主题要求（例如摸鱼绿）与已有微信封面／封面任务传入。明确：本轮已由 `$punk-cover` 负责微信封面，排版分支复用它，不再启动第二套封面。源文非 Markdown 时按依赖的归一化流程处理。

接收：可编辑 Markdown、干净 `<section>` 正文片段、复制预览、发布信息和依赖校验结果；标题、摘要及单独封面必须齐全。正文封面不混放。手动复制预览需要正文图时保留可携带的图片（本地既定交付为 data URI）；远端草稿上传另按工具支持转换为平台媒体，不假设 `draft/add` 会接受本地路径或 data URI。

必须执行依赖自带的 `validate_gzh_html.py` 与 `wrap_preview.py`，不重写校验器。结构检查、浏览器预览、真实编辑器粘贴和远端草稿回读分别记录；脚本通过不等于后三项通过。

## 小红书文案：xhs-note-creator / dbs-xhs-title

- `xhs-note-creator`：在贴图复用分支明确只走文案步骤，传入图片顺序与内容摘要，接收标题、正文、5–10 标签。原有图片足够时不执行其默认渲染。
- `dbs-xhs-title`：传入主题、领域／受众和真实素材；按它的公式匹配流程交付可追溯编号的候选、Top 3 与依据，最终标题≤20字（含标点）。不得为了套公式补造数字、人物、结果或承诺；不合适的公式跳过。

## 新卡片：baoyu-xhs-images / xhs-note-creator（按需）

只有用户要新卡片，或已说明现有图片不能承载内容时调用一个合适的卡片依赖，不同时生成两套同用途图片。

`baoyu-xhs-images` 的当前契约必须保留：

- 先读实际 `EXTEND.md` 与确认策略；仅用户当次明确 `--yes`、直接生成、不用确认等才跳过确认，不从“给了路径”推断同意。
- 每张图的最终完整提示词必须先保存到 `prompts/`，再调用它按当前运行时选择的图像后端；不替它另写 SVG／HTML／Canvas 生图方案。
- 第一张建立一致性锚点，后续图引用它，再按依赖批量政策生成；不为渲染另开子代理。
- 图片内文字错误时更新提示词、换新输出路径并重新生成，保留旧候选；不通过代码覆盖、擦除或重绘文字。

这些规则是接口约束，具体生成步骤与参数始终读依赖，不把其实现拷贝进本仓库。

## 推送工具

公众号：已配置的文颜 CLI 草稿能力，或官方草稿 API。X：当前连接工具清单中的 `article_create_draft`，名称可能带插件前缀。小红书：仅明确发布授权后才加载发布流程。

所有推送必须读取 [draft-push.md](draft-push.md)。工具不在当前清单时就标记未连接，继续本地交付；不能声称 Skill 文档里提到工具就代表工具已安装可用。
